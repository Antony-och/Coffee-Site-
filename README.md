# First Cup Coffee & Tea

A premium Kenyan coffee and tea storefront with a luxury editorial brand direction, export-focused product catalog, inquiry flow, and order/checkout experience.

## Preview

![First Cup Coffee & Tea homepage screenshot](./screenshot.png)

## Features

- Premium storefront landing experience for Kenyan coffee and tea
- Product catalog with coffee and tea collections
- Product detail modal and add-to-cart flow
- Cart drawer and checkout flow for order inquiries
- WhatsApp and email order submission
- Responsive layout for desktop and mobile browsing
- Brand-aligned copy, pricing, and product storytelling

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Lucide icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the app in your browser at:
   ```bash
   http://localhost:3001
   ```

## Production Build

```bash
npm run build
```

## Project Notes

This project is designed around a premium, export-focused coffee and tea brand experience inspired by East African highland sourcing, direct farmer relationships, and modern luxury retail presentation.
